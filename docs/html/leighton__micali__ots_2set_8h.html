Detailed Description

LM-OTS parameter set configuration.

Declares the compile-time LM-OTS parameter set selection macro and enumerates all valid LM-OTS typecodes defined in RFC 8554 Section 9.1. This configuration determines the hash function and Winternitz parameters used throughout the library.

enum VERUM_LEIGHTON_MICALI_OTS_typecode

Valid LM-OTS typecodes per RFC 8554 Section 9.1.

Enumerates the standardised LM-OTS parameter sets defined by the IANA LM-OTS Typecode Registry. Each typecode encodes a hash function and Winternitz parameter (w), which determine n, p, and ls as specified in RFC 8554 Section 2.

See also
https://www.rfc-editor.org/rfc/rfc8554#section-9.1
https://www.iana.org/assignments/leighton-micali-signatures/
